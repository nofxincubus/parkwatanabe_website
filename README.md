# Park Watanabe LLC — Official Website

Official website and landing page for **Park Watanabe LLC**, creators of **CloudAudio** and **WishWhale**.

Hosted on **GitHub Pages**.

## Structure
- `index.html` - Main landing page featuring studio overview, product showcases (CloudAudio, WishWhale), core principles, and contact/support details.
- `privacy.html` - App Store / Google Play compliant Privacy Policy.
- `terms.html` - Terms of Service agreement.
- `.nojekyll` - Prevents Jekyll from processing static assets on GitHub Pages.

## How to Deploy on GitHub Pages
1. Push this repository to GitHub (`main` or `gh-pages` branch).
2. Go to repository **Settings** -> **Pages**.
3. Under **Build and deployment**, select **Deploy from a branch** and set the branch to `main` with `/ (root)` folder.
